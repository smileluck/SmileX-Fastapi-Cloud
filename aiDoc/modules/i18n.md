# core/i18n —— 后端响应消息国际化

## 职责

按请求语言返回后端响应消息（统一返回 `msg`、异常消息、Pydantic 校验消息）。语言由 `Accept-Language` 请求头决定，文案用 YAML key 目录管理，支持 `{name}` 命名占位符做动态字段插入。

## 入口

- 对外 API：`from core.i18n import t` → `t("ns.key", **kwargs)`
- 中间件接入：`core/middleware/share_middleware.py` 的 `RequestContextMiddleware`（最外层纯 ASGI）解析 `Accept-Language` 并 set/reset 语言 ContextVar
- catalog 预加载：`core/registry/setup_registry.py` 的 `setup_app` 中 `load_catalogs()`

## 结构

| 文件 | 职责 |
|---|---|
| `context.py` | `language_ctx: ContextVar[str]`（默认 = `I18N.DEFAULT_LANGUAGE`）+ `get/set/reset_current_language`，镜像 `tenant_id_ctx` |
| `catalog.py` | 加载 `locales/*.yaml` 为内存扁平 `{locale: {dotted_key: template}}`；`get_catalog()` 懒加载、`reload_catalogs()` 热更新 |
| `translate.py` | `translate(locale, key, **kwargs)` + `t(key, **kwargs)`；`_SafeDict` 保证缺占位符/格式错误不抛异常；回退链 locale→FALLBACK→DEFAULT→raw key；dev 模式缺 key 打 warning |
| `accept_language.py` | `resolve_language(header, supported, default)`，RFC 质量值 + 主语言前缀双向匹配，纯函数 |
| `locales/zh-CN.yaml`、`en-US.yaml` | 文案目录（key 1:1 对齐） |

## 命名空间约定

- `response.*` 对应 `CustomResponseCode`；`error.*` 对应 `CustomErrorCode`（按领域分组）+ 异常处理器兜底
- `pydantic.*` 对应 `PYDANTIC_ERROR_MSG_MAP`；`common.*` 通用成功/批量模板；`validation.*` 校验器 ValueError；`<模块>.*` 业务模块专属

## 与现有体系的集成

- `CustomCodeBase`（`core/response/response_code.py`）：`.msg` 属性按 `.key` 懒翻译；枚举成员元组第二位即 i18n key；`.code` 数字不变
- 异常类（`core/exception/errors.py`）：每个类用 `default_msg_key` 声明默认文案 key，构造期 `msg is None` 时按当前请求语言翻译
- 异常处理器（`core/exception/errors_handler.py`）：所有兜底走 `t(...)`；`CustomError`/`OpenApiError` 走 `exc.err_code.key`

## 配置（`I18nModel`）

- `DEFAULT_LANGUAGE`（默认 `zh-CN`）：无 `Accept-Language` 时使用
- `SUPPORTED_LANGUAGES`（默认 `["zh-CN","en-US"]`）：支持语言，对应 `locales/` 文件名
- `FALLBACK_LANGUAGE`（默认 `zh-CN`）：key 在请求语言缺失时回退

## 扩展新语言

加 `locales/<locale>.yaml`（key 与 `zh-CN.yaml` 对齐）+ 追加到 `I18N.SUPPORTED_LANGUAGES`，不改代码。

## 不翻译的边界

`logger` 日志串、Pydantic `Field(description=)`、FastAPI `summary=`、启动/基础设施层错误（DB 池、URL 构建器、雪花 ID、config loader 等）保持原文。跨栈契约见 `aiDoc/frontend-backend/boundary.md` 的「国际化」一节。
