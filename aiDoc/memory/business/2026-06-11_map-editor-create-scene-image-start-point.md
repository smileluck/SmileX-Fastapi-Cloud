# 地图编辑器新增场景图片与起始点位

## 需求描述

地图编辑器新增场景时需要上传场景图片，并录入基于网页实际显示图片的点位 `x`、`y` 与角度。点位坐标需要按原图尺寸与网页显示尺寸的比例缩放后保存为地图标注坐标。

## 状态

已完成

## 涉及范围

### 后端

无新增接口；复用场景地图创建接口与编辑器保存接口。

### 前端

- 地图编辑器新增场景弹窗增加图片上传
- 新增场景弹窗展示原图尺寸，并用图片当前网页渲染尺寸作为可视尺寸
- 新增场景弹窗增加起始点位 `x`、`y`、角度输入
- 创建场景后自动创建“起始点位”导航点并保存

## 约束与备注

- 场景地图保存的宽高使用上传图片返回的原图宽高
- 起始点位按 `原图宽 / 图片网页显示宽`、`原图高 / 图片网页显示高` 分别缩放
- 缩放后的点位保存为地图编辑器画布坐标，角度原样保存
