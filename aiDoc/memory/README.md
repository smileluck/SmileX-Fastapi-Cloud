# 记忆层

`aiDoc/memory/` 是 AI 的记忆层，用于记录跨会话有效的上下文信息。

## 目录说明

- `long-term/`: 长期稳定的用户偏好、协作方式、跨任务约束
- `business/`: 每次用户提出的业务需求记录
- `lessons/`: 开发踩坑与复发模式的经验记录，达到晋升条件后写进约束正文

## 使用规则

- 记忆是给 AI 用的，不是通用笔记存储
- 用户提出业务需求时，AI **必须**新增或更新一条 `business/` 记忆
- 当某条业务需求反复出现或沉淀为稳定模式时，提炼到 `long-term/`
- 临时会话草稿不要入库，只有变成长期知识时才记录

## 相关文件

- `project-memory.md`: 记忆索引
- `long-term/`: 长期记忆目录
- `business/`: 业务需求记忆目录
- `lessons/`: 经验教训目录
